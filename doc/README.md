# Myanmar Logistics & Tracking Prototype Documentation Pack

This pack consolidates the attached assignment and all 300 Grill-Me design decisions into one implementation source of truth for a five-person team.

Start with:
1. `decision-log-001-300.md` for every question and decision.
2. `02-system-architecture.md` through `15-five-person-execution-plan.md` for implementation specifications.
3. `mermaid/` for editable Mermaid source diagrams.
4. `html/` for browser-viewable Mermaid diagram pages (requires internet to load Mermaid JS).
5. `Myanmar_Logistics_Project_Master_Documentation.docx` for the consolidated Word document.

The pack clearly distinguishes assignment requirements from team extensions such as real GPS, Driver-controlled rerouting and pheromone-inspired learned routes.
